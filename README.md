Solana Account Viewer

About the Project

Solana Account Viewer is a web application that allows users to enter multiple Solana wallet addresses and view their SOL balances on the Solana Devnet network.

Features

- Add multiple Solana wallet addresses.
- Retrieve wallet balances using Solana Devnet RPC.
- Display balances in SOL.
- Validate wallet address formats.
- Remove wallet addresses.
- Save wallet addresses using browser localStorage.
- Restore saved wallets when the application is reopened.

Technologies Used

- HTML
- CSS
- JavaScript
- Solana Devnet RPC API
- Browser localStorage

Network

Solana Devnet

RPC Endpoint: https://api.devnet.solana.com

How to Use

1. Open the application.
2. Enter a Solana wallet address.
3. Click Add Wallet.
4. View the wallet's SOL balance.
5. Add more addresses to monitor multiple wallets.
